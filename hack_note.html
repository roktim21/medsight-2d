  • ✅ Patient‑friendly + clinical summaries
  • ✅ Context‑locked chat assistant (Gemini)
  • ✅ Text‑to‑speech, flagged terms with definitions
  • ✅ Zero permanent storage — memory only

📡 API Endpoints

GET /api/health
Service health & Gemini key status
POST /api/analyze
Upload base64 image/PDF → structured MedicalAnalysis
POST /api/chat
Context‑aware Q&A with Gemini, returns reply + suggestions
fallback If GEMINI_API_KEY missing → mock structured responses

⚙️ Backend

  • • Express with 20MB body limit
  • • Gemini system prompt enforces safety & dual perspectives
  • • Response schema (Type.OBJECT) ensures structured JSON
  • • Media parser: data URLs, raw base64, SVG → normalized
  • • Fallback mode when API key absent (mock data)

🎨 Frontend

  • • App state: analysis, loading, media, activeTab
  • • Chat context‑locked to analyzed media
  • • Glassmorphism design (cyan accent #00E5FF)
  • • Zero‑persistence banners & safety modal
  • • TTS (speech synthesis) for assistant messages
